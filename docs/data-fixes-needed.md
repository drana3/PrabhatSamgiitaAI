## Что уже исправлено в коде (для справки)

- Плеер: демо-слова и русские строки больше не попадают на реальные песни; они видны только в режиме демо, только для песен 1 и 3, с пометкой "Demo content". Иначе честное пустое состояние.
- API: клиент получает только аудио и видео со статусом `verified`, `verified_external` или `human_reviewed`; YouTube из БД и из `youtube_videos.json` сливается для каждой песни без дублей по embed id; порядок стабильный; "лучшее" аудио определяется правилом.
- Скрипты YouTube: номер в названии больше не достаточен для `verified` (год, дата, длина, часть, программа, несовпадение названия отправляют в очередь на проверку).
